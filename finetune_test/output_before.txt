Claro! Vou criar um script C# básico para um controle de personagem 2D simples em Unity para um jogo mobile (iOS/Android). Este script fará com que o personagem se moveia lateralmente com toque na tela e haja um pulo com física básica usando `Rigidbody2D`.

1. **Crie uma nova Cena**:
   - Inicie o Unity.
   - Clique no botão "File" > "Create" > "New Scene".

2. **Adicione um Personagem**:
   - No Inspector, clique no botão "+" para adicionar um GameObject.
   - Selecione "2D Object" e clique em "Add Component".
   - Escolha "Box Collider 2D" e clique em "Add Component".
   - Adicione um "Rigidbody 2D" e clique em "Add Component".
   - Adicione um "Sprite Renderer" e clique em "Add Component".
   - Adicione um "Animator" e clique em "Add Component".

3. **Configure o Personagem**:
   - No Inspector, selecione o Personagem e configure os atributos como quiser: cor do sprite, tamanho, etc.

4. **Criar o Script**:
   - No Inspector, clique no botão "+" para adicionar um novo script.
   - Nomeie o script "PlayerController.cs".

5. **Adicione o Código ao Script**:
   - Abra o arquivo "PlayerController.cs" e adicione o seguinte código:

```csharp
using UnityEngine;

public class PlayerController : MonoBehaviour
{
    public float speed = 5f; // Velocidade de movimento
    public float jumpForce = 10f; // Força do pulo

    private Rigidbody2D rb;
    private Vector2 movementInput;

    void Start()
    {
        rb = GetComponent<Rigidbody2D>();
    }

    void Update()
    {
        // Ler input do teclado
        movementInput.x = Input.GetAxis("Horizontal");

        // Aplicar velocidade
        rb.velocity = new Vector2(movementInput.x * speed, rb.velocity.y);

        // Pular
        if (Input.GetKeyDown(KeyCode.Space))
        {
            rb.AddForce(Vector2.up * jumpForce, ForceMode.Impulse);
        }
    }
}
```
